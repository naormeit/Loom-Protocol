The failure mode

Agent commerce breaks when every bot reaches checkout at once.

Direct vendor APIs were not designed for thousands of autonomous shoppers reserving one scarce item at the same time. The result is duplicate holds, retry storms, ambiguous partial state, and no machine-readable path for the losing agents.

Loom moves the concurrency decision upstream. Agents submit intent first. The protocol returns either a confirmed lock or a structured negotiation payload for safe retry.

Protocol path

One request, five gates, one clear result.

  1. 01 Intent packet

    Agent submits `agent_id`, `intent`, `intent_hash`, and lock expiry.

  2. 02 Authority

    Signature mode verifies packet authenticity and rejects replay attempts.

  3. 03 Microsoft AI

    Intent parsing and content safety prepare the packet for transaction logic.

  4. 04 Atomic ledger

    Local mode proves one-winner behavior. Azure mode targets Cosmos DB locks.

  5. 05 Negotiation

    Losing agents receive `409` plus an alternative resource and retry backoff.
